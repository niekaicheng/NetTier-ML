# Outside the Closed World: On Using Machine Learning for Network Intrusion Detection
**Authors**: Robin Sommer, Vern Paxson
**Date/Venue**: IEEE Symposium on Security and Privacy (SP), 2010

## 核心提要 (Core Summary)
本文深入探讨了在网络入侵检测系统 ([[NIDS]]) 中应用机器学习（特别是异常检测）所面临的基础性挑战。尽管机器学习在其他领域取得了巨大成功，但由于网络环境的独特性，基于异常的入侵检测系统很少在实际环境中成功部署。

## 关键挑战 (Key Challenges)
1. **异常检测的误差代价**
   - 机器翻译没翻译好影响不大，但在 NIDS 中，一次误报（False Positive）会浪费极其宝贵的网络分析师调查时间。
2. **什么是正常 (What is Normal?)**
   - 寻找网络中“稳定”的正常基线是极度困难的。网络流量具有极大的多样性和不可预测性（例如：[[网络流量的自相似性]]）。
3. **[[封闭世界假设 (Closed World Assumption)]] 的失效**
   - 异常检测往往隐式地假设“异常项就是攻击”。在网络中这种假设无效，大部分异常只是流量中的合法“噪音”或协议畸变。
4. **[[语义鸿沟 (Semantic Gap)]]**
   - 机器学习模型给出的“离群值”往往不能等同于运维人员手上的“系统攻击”，导致“误报过多”。
5. **极高的对抗与规避风险**
   - 网络是一个高度动态对抗的环境，攻击者可能通过构造训练时期的数据毒化来降低系统的灵敏性。

## 作者的建议 (Recommendations)
应当缩小异常检测系统的泛用野心，专注于特定的、目标明确的攻击检测系统。最高指标是采用人类网络操作员的视角看问题：如果你的预测对防守方有用，那就对了。甚至作者抛出了最后的观点：如果你深入排查并完全理解了你正在找的异常，**你可能根本不需要机器学习**。
