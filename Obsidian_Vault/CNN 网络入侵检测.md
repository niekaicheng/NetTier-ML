# CNN 网络入侵检测

## 概念
传统概念里，**卷积神经网络 (CNN)** 几乎就是“图像处理 (Computer Vision)”的代名词。但在网络安全领域，通过将一维的流量包序列或特征流映射转换（有时转换为类 2D 前置图像），也能使用 CNN 逆天的局部特征提取功效来做安全检测。

## 优势 (相较于普通全连接层/浅模型)
1. **摒弃全节点点乘**：不需要像普通深度前馈网络 (FNN) 或是随机森林那样硬算，通过卷积核滑动（Convolution + Stride）可以捕捉网络包载荷之间微妙的上下文（Context）关系。
2. **抵抗过拟合**：引入池化层（Pooling）后压缩特征矩阵，能在不抛弃致命线索的前提下大幅减少训练参数，使得对未见过的变种攻击 (Zero-day) 表现出惊人的抗锯齿/鲁棒性。

> 参考文献：在 [[NIDS using Deep Learning (Ashiku & Dagli 2021)]] 论文中，作者使用了 Double Stacked CNN 的架构在最新版基准数据集拿下了 95.6% 的高精度。
